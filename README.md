# 🧮 Interactive Counter App

A sleek, responsive Counter App built with vanilla HTML, CSS, and JavaScript. It features smooth interactive controls and a dynamic dual-background image layout to create an engaging visual aesthetic.

## ✨ Features

* **Core Functionality:** Increment, decrement, and reset counter values with real-time DOM updates.
* **Dual Background Visuals:** Blended background image layers to create depth and texture.
* **Responsive Design:** Optimized layout for seamless use across desktop and mobile screens.
* **Clean Codebase:** Modular structure utilizing pure HTML5, modern CSS3 styling, and clean JavaScript logic.

## 🛠️ Tech Stack

* **HTML5:** Semantic markup structure.
* **CSS3:** Custom styles, Flexbox/Grid layouts, and multi-layered background properties.
* **JavaScript (ES6+):** Event handling, state management, and DOM manipulation.
